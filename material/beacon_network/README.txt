Beacon network project files
- beacon_app.html       Interactive simulator (open in any browser, works offline except web fonts)
- beacon_storage.tex    IEEEtran paper source (directives for LLMs at top). Compile with a full TeX install or Overleaf.
- beacon_storage.pdf    One-page IEEE-style preview (built with the article class, not true IEEEtran)
- beacon_sim.py         Python script that generates the figure (needs numpy, matplotlib)
- beacon_network.png/.pdf  Simulation figure
